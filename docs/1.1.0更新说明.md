# 1.1.0 更新说明

- 采用暖白底色、蓝粉课程卡片及分区时间表，调整手机布局和弹窗。
- 默认作息改为参考 PDF 的 10 节课，新增大课间、午休、晚餐空白活动行。
- 保留原始课程及五角星时间指示；跨活动课程分段展示、统一编辑。
- 底部新增“课表 / 事务待办”导航。
- 新增待办增删改、日期时间、优先级、备注、完成状态与筛选。
- 新增安卓本地系统通知、权限引导、后台调度及通知取消。
- 备份同时包含课表与待办，兼容旧备份；恢复默认课表保留待办。
- 未修改的旧默认作息自动升级，自定义作息及使用第 11 节的安排保留。

安装前建议导出备份；覆盖安装沿用原签名。系统通知需要用户允许，准时提醒需开启系统闹钟和提醒权限。

本次只交付本地 APK 与源码，不执行 GitHub 推送或 Release 发布。
