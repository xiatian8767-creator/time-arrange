# 1.2.0 离线搭子课表

新增搭子管理弹窗：配置导入、联网申请占位、导出本人课表配置，以及导入后的移除入口。主课表页支持一键切换，只读搭子课表使用独立作息，课程详情展示地点及备注。

配置格式沿用 version 2 的 slots/courses；导出不包含 todos。导入兼容 version 1/2 的个人备份，但仅校验并提取 slots/courses，忽略待办及其他字段。文件最大 1 MB，保存前需确认，错误保留原有配置。

Android 在 star_schedule SharedPreferences 新增 partner 键，个人 data 键及提醒逻辑保持独立。浏览器预览使用 star-partner。搭子副本不包含在个人完整备份内，需保留原始配置。应用启动默认展示本人课表。

原生文件选择器分别回调 importBackup/importPartner，选择用途在 Activity 状态恢复时保留。版本 1.2.0、versionCode 4，沿用本机签名，未新增网络权限。
