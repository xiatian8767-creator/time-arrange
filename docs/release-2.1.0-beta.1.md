# Star Orbit 2.1.0-beta.1 · 内测探索版

- 全新深蓝金色星环图标。
- 毛绒星小助：微笑、打盹、眨眼、开心四种表情，连续缓慢漂浮；可拖动、固定或隐藏。打开对话和编辑页面时暂停活动。
- 闹钟回归待办：每条待办单独开启，可在到点、提前 5/10/30 分钟或自定义日期时间响铃。
- 已有待办保留原通知设置，新增闹钟默认关闭。不再提供独立闹钟列表，“提醒保障”移除，改为直接打开安卓授权流程的“通知权限”。
- 半透明全屏待办闹钟界面，仅展示本次触发的标题和提醒时间。支持滑动关闭、停止响铃、稍后 5 分钟；关闭响铃不会完成待办。
- 星环宇宙下载页：离线免费版 1.2.5、内测稳定版 2.0.0-beta.4、内测探索版 2.1.0-beta.1。两个旧安装包保持不变。

## 更新与兼容

安装包 `StarOrbit-2.1.0-beta.1.apk`，versionCode 13，沿用原包名与签名，可覆盖更新。先导出备份；三个版本不能作为不同应用同时安装，回退旧版可能需要卸载。

课表文档仍是 version 2，待办新增可选 `alarmEnabled` 和 `alarmAt` 字段。缺省 false/0。新服务端兼容旧客户端：旧客户端只改标题、备注等时保留原闹钟，改变待办时间而未提供闹钟字段时关闭闹钟，避免在旧时间意外响铃。闹钟时间随个人数据同步，通知和锁屏权限仍由每台设备单独授权。搭子不能读取待办。

Beta.4 的独立闹钟取消调度，旧记录不删除，也不自动转换成待办。旧的全局响铃开关不再生效。

## 使用边界

响铃最长 10 分钟；完成、删除、关闭闹钟或切换账号会取消不再有效的响铃与稍后提醒。连续提醒同时触发时统一显示，不展示其它待办或备注。

安卓通知、准时闹钟、锁屏全屏提醒需要授权。系统可能在解锁时只显示悬浮通知；厂商省电、强行停止应用、关机等仍可能影响送达，不承诺绕过系统限制。后台服务仅在响铃期间运行。

实现参考：[安卓闹钟调度](https://developer.android.com/develop/background-work/services/alarms)、[全屏提醒限制](https://source.android.com/docs/core/permissions/fsi-limits)。

视觉素材及生成提示词见 [素材说明](visual-assets-2.1.md)。
