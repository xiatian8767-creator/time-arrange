# Star Orbit 3.3beta.2

## 用户端

- 课表顶部日期、周切换、星币与头像按三等分排布。
- 搭子头像下方的小菜单仅保留发送弹窗、赠送星币。
- 两种送礼界面支持自定义图片，去掉颜色、时间、复用模板选项。
- 成功发送后撒花，再显示小型成功提示。
- 收礼弹窗使用暖金/淡蓝主题，宽度 68%、高度 66%，长留言内部滚动。
- 头像设置只保留白底“选择照片”。

## 后台

- 赠币弹窗预览与客户端使用同一渲染模板。
- App 弹窗仅展示管理员任务；用户间留言和礼物继续正常投递，但不能在运营任务接口中修改、删除或重置。
- 新增 star_gift_presentations 表保存礼物数量，不修改原有余额事务。
