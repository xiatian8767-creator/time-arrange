# Star Orbit 2.1.0-beta.3 · 探索版

手机主界面两侧留白缩小至 8 px，让课表更宽一些，其它布局保持不变。

本次 GitHub 发布也包含上一轮界面更新：

- 课表管理默认折叠；有搭子才显示切换，搭子课表保持只读。
- 统一课表、待办、设置及星小助页面；简化不必要的说明文字。
- 时间采用小时 / 分钟双列滚动，仅保留取消和完成。
- 星小助有独立首页和快捷输入，不显示服务商连接状态。
- 官网采用星环动画和简洁特点区，只提供最新探索版下载。
- 后台采用侧栏和表格布局，反馈详情支持宽屏侧栏与手机弹层。

已有课表、待办、背景和闹钟设置保留。未修改存储结构、接口、提醒调度、后台保活或证书。本轮不包含 vivo 提醒保活或稍后五分钟的功能修复。

支持覆盖升级，安装前建议导出备份。安装包为 `StarOrbit-2.1.0-beta.3.apk`（versionCode 15）。
