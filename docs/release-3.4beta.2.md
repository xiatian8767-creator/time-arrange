# Star Orbit 3.4beta.2 探索版

## 用户变化

- 修复图片任务追问丢上下文：补充时间、标题时携带未完成任务的原图和完整结构化回复。即使普通历史超过四轮，也保留当前未完成图片任务；只在内存中保留，清空对话或切换账号即释放。
- 保留原有客户端建议解析、字段校验、修改预览和确认保存流程。信息齐全时提示模型直接给出操作建议，不再反复要求口头确认。确认前不写入，确认后标记任务已保存。
- 同一会话优先使用同一个健康且具备对应能力的 API，故障再切换。旧客户端未提供会话编号时仍沿用请求轮询。

## 服务与后台

- 服务端仅处理模型转发、协议与用量校验、密钥容错及星币结算，不解释、修正或执行课表/待办操作；返回原始建议，由客户端决定是否需要格式校正及用户确认。
- 后台输出上限允许配置到131072。已知 DeepSeek / Qwen3.8 模型请求上限为131072，Qwen3.5–3.7为65536，其他模型采用32768的保守上限。模型实际权限或能力变化仍可能导致拒绝，新增模型需核实官方参数。
- 模型超时允许5–300秒，建议180秒；整次路由预算300秒。代理330秒、安卓320秒、网页等待325秒；未完成预留超时恢复改为10分钟，避免长任务仍运行时提前退款。单进程启动恢复机制保留。
- 模型响应读取上限4MiB、安卓接收上限8MiB，文本上下文上限1MiB；图片仍最多10张，总请求受4MiB代理限制。长上下文不等于无限历史。
- 不自动提高星币倍率、单次费用上限或钱包余额。输出配置是上限，不是每次固定生成量。若实际费用超过余额/上限，仍不交付并退回本次预留；应由管理员按业务需要自行调整上限。
- Key 不下发给客户端，后台 API 列表、访问记录和统一规则保留。

版本代码29，沿用原签名。官网首页版本暂不替换，先提供探索版安装包与更新链接。
