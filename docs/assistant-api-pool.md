# 星小助 API 池（3.4beta.1 服务端兼容更新）

无需重装 App，不改官网安装包。原来的单 Key 与计费规则会在首次启动时迁移，不会重新生成密钥加密主文件。已有访问记录保留。

## 后台使用

- [API 列表](https://8.154.43.154:8443/admin/assistant/apis/)：添加、编辑、停用、删除 API；选择 DeepSeek / Qwen、模型、地域、图片能力和超时。编辑时 Key 留空保留原值，切换服务商或地域时须重新填写 Key。删除有确认，已删除 API 的历史调用快照仍保留。
- [用户访问记录](https://8.154.43.154:8443/admin/assistant/usage/)：按用户与状态筛选；展示最终 API、token 用量、星币结算和每一步切换路径，不展示用户的文字或照片。
- [统一计费规则](https://8.154.43.154:8443/admin/assistant/rules/)：全局启停、时段价格、倍率、每元星币数及单次上限。所有 API 使用这一套规则，不按供应商分别定价。

Key 加密入库，不会发送给 App，也不能通过后台接口读回。最多配置50个 API。Qwen 默认建议 `qwen3-vl-plus`；仅勾选实际支持图片的模型。国内 Key 选北京，国际 Key 选新加坡，不能跨地域混用。

## 请求与容错

1. 每次模型请求在已启用、未处于冷却中的 API 中轮询。图片请求只选支持图片的 API。
2. 鉴权失效、余额不足、限流、网络故障、上游错误或无效回复会记录失败，尝试下一个可用 API。同一请求不会重复尝试同一个 Key。
3. 401/402/403 一般冷却15分钟；429及其他上游 HTTP 错误一般1分钟；网络、超时或回复格式错误一般30秒。可在后台“解除冷却”，或更新 Key 后恢复。
4. 内容安全拒绝不切换其他供应商，不绕过内容审核。所有 API 都不可用时，返还本次预留，不收取本次费用。
5. 调用总预算约65秒，每个 API 超时可设5–60秒，受剩余预算约束。慢 Key 可能消耗本次预算，不保证每次能尝试整个池；建议配置约20–30秒超时。
6. 只有最终有效回复参与用户结算，失败尝试由平台承担成本，不叠加扣用户星币。继续使用原有请求幂等、预留退款及修正回复合并计费逻辑。

统一星币公式：`ceil((缓存命中token×命中价 + 未命中输入token×未命中价 + 输出token×输出价) / 1000000 × 倍率 × 每元星币数)`。默认倍率5，每元100枚，每次按整数向上取整。Qwen 的缓存用量会转换到同一计费口径。

## 运维边界

新增三个独立数据表：`assistant_api_keys`、`assistant_billing_rules`、`assistant_api_attempts`。迁移成功后清空旧配置表的密钥字段，避免双份配置；原备份仍保留。若回滚旧版代码，应同时恢复对应旧配置备份，不能直接期待旧代码读取新 API 池。

当前采用单 API 容器、单 worker，轮询游标在进程内维护，重启后重新开始。不要在未改造预留恢复与分布式游标之前扩展多 worker / 多实例。密钥主文件继续只读挂载，不轮换、不输出；不影响另一项目的容器、数据库或网络。

适配依据：[Qwen OpenAI 兼容接口](https://help.aliyun.com/zh/model-studio/qwen-api-via-openai-chat-completions)、[DeepSeek 错误码](https://api-docs.deepseek.com/quick_start/error_codes/)。真实供应商可用性仍取决于管理员填写的 Key 权限、余额及模型开通情况。
