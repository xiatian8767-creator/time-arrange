# 星课表 1.0.0 验证记录

验证日期：2026-09-08。最终 APK 为非调试构建，包名 `cn.xingke.timetable`，版本号 1 / 1.0.0。

## 已通过

- APK 编译、DEX 转换、压缩对齐和签名校验。
- Android 15 / API 35、1080 × 1920 模拟器：安装、启动，以及最终签名安装包的覆盖安装和冷启动。
- 安卓测试时 Wi-Fi 和移动数据关闭，系统显示 `Active default network: none`，应用仍可加载全部内置课表资源并使用编辑功能。
- 安卓本地存储：新增课程后从 14 增至 15 个课程块，第一节开始时间改为 08:05；页面重载和强制停止后冷启动，课程数量和时间均保留。
- 安卓系统文件选择器：保存真实 JSON 备份至 Downloads，恢复初始课表后选择该文件导入，确认后恢复 15 个课程块及 08:05 时间；重启后再次确认。
- 交付包内初始值保持图片的 14 个课程块、11 节可读作息；测试中的临时课程未写入源代码或交付包。
- 清单不包含任何 `uses-permission`，没有网络权限。交付包非 debuggable，WebView 调试仅在测试构建开启。
- 浏览器端手机布局：320、360、390、430 像素宽及 760 像素宽均无横向溢出；查看了主界面、编辑窗口、设置窗口和安卓显示截图。
- 浏览器交互回归：新增、编辑、删除确认、课程冲突拒绝、作息修改持久化、时间重叠拒绝、占用节次删除保护、备份导出及恢复、非法备份拒绝、周切换和跨午夜刷新；无未捕获页面异常。
- 8 项时间与数据逻辑测试：图片初始课表，课内/课间/午休/课前/课后五角星位置，跨年周日期，冲突与非法时间，中文数据备份往返，上下课边界，作息修改联动，连续课程中途休息。

## 验证范围

实际安卓安装测试使用模拟器，未在用户的实体手机上测试，也未覆盖所有安卓品牌和系统 WebView 版本。最低安装版本为 API 23；旧手机的系统 WebView 仍需支持现代 JavaScript。课程按周重复，不含单双周、教学周筛选或提醒通知。

## 可重复验证

源码根目录运行 `node --test tests/core.test.js` 可执行 8 项逻辑测试。运行 `build.ps1` 会自动重新构建并校验 APK 签名与压缩对齐。全部构建源码随源码压缩包提供，Android SDK 与 JDK 不在源码压缩包中。
