# 2.0.0-beta.1 验证记录

日期：2026-10-02。该记录区分已验证与待验收项，不代表公网正式上线。

## 已通过

- 后端自动化：9 项，涉及注册登录、跨设备读取、过期版本 409、刷新凭证轮换、退出、搭子邀请权限及幂等、解绑、私有待办不外泄、非法 JSON 字段/冲突课程/格式/大小/限流。
- JS 核心：14 项（原课表 9 项、AI 提议 5 项）。验证原始对象不被提议修改、取消无需写入、越权/未知操作/坏字段/无效引用被拒绝、替换课表保留待办。
- 浏览器集成：真实本机 API + 模拟 Android bridge。注册后同步、多设备冲突选择、一对一邀请与解绑、搭子结果无 todos、AI 预览/取消/确认/过时提议失效、拖动及 320/390/760 宽度、退出恢复访客。
- 1.2.4 UI 回归：无搭子零占位，静态导入/移除、内嵌文字滑轨、双向拖拽和键盘切换、只读页隐藏操作栏、重载保留、响应式布局。
- Android 15 模拟器：APK 安装与启动，原生 Keystore 存取并在 WebView 重载后保持，检查私有 SharedPreferences 中测试 Key 不为明文；原子切换账号、恢复访客、明确拒绝 HTTP。
- Android 真实 HTTPS/PATCH 探测：向 DeepSeek 官方端点发送无 Key、无用户数据的非模型请求，收到 HTTP 401，证明原生 TLS、DNS 和 PATCH 请求可达。起初失败因旧测试模拟器开启飞行模式，恢复网络后通过；没有放宽证书验证。
- Android 系统相机：用模拟器虚拟相机拍摄、确认，成功回到 AI 页面显示图片并填入识别提示。未将图片发送给模型；私有 capture.jpg 在处理后清理。
- 阿里云内部部署：`/opt/xingke-v2`，健康检查 `{ok:true,version:2.0.0}`。仅回环 `127.0.0.1:18080`，PostgreSQL 没有宿主机公网映射；旧下载站保持原容器和端口。
- 实际 PostgreSQL 独立随机 schema 并发测试：两份竞争邀请只有一份能接受；同一 revision 的并行写入只有一份成功；同一 refresh token 的并行兑换只有一次成功。临时 schema 已清理，不写正式用户表。

## 仍需确认 / 未宣称通过

- 手机连接真实公开 API 的端到端验收：目前没有公网 HTTPS 入口，域名未完成备案。IP 可配 HTTPS，但不能视为绕过内地服务器备案要求。
- DeepSeek/Qwen 的真实付费模型对话、Key 权限/地域/额度、真实课表照片识别准确率：没有用户 Key，不消耗模型额度。AI 确认流程使用模拟回复验收。
- 真机各品牌相机、旋转与通知后台限制，Android 6–14 的兼容性：本轮系统测试仅 Android 15；编译 minSdk 为 23，不等于所有版本已实测。
- 数据库长期备份及恢复、TLS 续期、对外公开前的安全和合规检查。
