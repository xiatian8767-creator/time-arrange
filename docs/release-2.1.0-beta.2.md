# Star Orbit 2.1.0-beta.2

本次为界面更新，Android versionCode 14，沿用原包名与发布签名。

- 课表管理区默认折叠；有搭子时才显示课表切换，搭子课表不提供编辑操作。
- 待办、设置和星小助页面采用统一的深蓝、暖金、月白样式。
- 时间改为应用内小时 / 分钟双列滚动选择，仅提供取消和完成。适用于待办、作息、自定义闹钟，保留任意分钟精度。
- 星小助新增首页和快捷输入；首页及对话不展示服务商或连接状态，服务商与 Key 在设置中保留。
- 发布页采用全幅星环动画及简洁特点区，只展示最新探索版下载。旧安装包保留在服务器，不在发布页列出。
- 运营后台采用侧栏和表格布局；宽屏反馈详情在右侧处理，小屏使用弹层。

不更改 JSON 结构、数据库、同步协议、权限策略、提醒调度、后台保活或证书。已有课表、待办、背景设置和闹钟状态保持原样；闹钟不会因本次界面更新自动开启。

更新前建议导出备份。安装包为 `dist/StarOrbit-2.1.0-beta.2.apk`。
