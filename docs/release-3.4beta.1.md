# Star Orbit 3.4beta.1 · 星小助星币对话

- 星小助改用星币对话，无需填写个人 API Key。
- 每条回答下方以小字显示本次消耗的星币，钱包增加“星小助对话”记录。
- 文字对话、最多十张图片识别、课表和待办修改建议均继续支持，实际保存仍需确认。
- 生成失败不扣费；同一请求查询或重试不会重复扣费。自动格式校正合并计算后取整。

版本代码 28，沿用原签名。后台新增“星小助系统”，可配置模型 Key、峰谷单价、倍率、汇率、费用上限、节假日日历和开关，并查看计费记录。

初始规则：DeepSeek V4.1-Flash（`deepseek-flash`）官方人民币 token 价格的5倍，1元=100星币，每条用户对话向上取整为整数星币。实际模型服务需要管理员在后台填写有效 Key 并启用。

## 验证与投放

- 18项后端/钱包测试通过，1项需独立PostgreSQL的旧用例跳过；新增独立PostgreSQL并发验证另行通过，覆盖重复请求、预留余额防重复消费、结算、幂等回放，临时库已清理。
- 浏览器检查通过：星币费用展示、合并校正计费、余额不足、十张照片随消息发送、修改前确认、后台配置与CSRF。
- 安装包签名与对齐检查通过。
- 后端与配置页面已部署；实际 DeepSeek 请求待管理员填写自己的 Key 后验收，未借用其他项目密钥或扣真实用户测试费用。
- 延续先测试再发布官网的流程：GitHub预发布提供3.4beta.1，官网暂保留3.3beta.3稳定版和3.3beta.4探索版，等待本次验收后替换探索版。
