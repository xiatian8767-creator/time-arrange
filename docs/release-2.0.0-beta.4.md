# Star Orbit 2.0.0-beta.4

- 星课表更名为 Star Orbit，沿用包名、签名及数据位置，支持覆盖更新。
- 星小助变为可拖动的小星团，支持自由活动、固定位置和隐藏；打开对话或设置时暂停活动。
- 新增本机独立闹钟，支持持续响铃、震动、关闭和 5 分钟稍后提醒；待办可选择通知或闹钟提醒。
- 设置增加提醒保障入口，检查通知、准时闹钟、锁屏提醒及后台运行设置。
- 精简设置中的技术说明，隐藏 AI 连接参数，保留服务商选择与 API Key；服务器地址仍可填写。
- 新增独立管理员网站：登录、按用户名/昵称/ID 模糊查询、重置用户密码。重置后旧会话失效。

## 安装

安装 `StarOrbit-2.0.0-beta.4.apk`，versionCode 12。更新前请导出备份。稳定版下载仍保留 1.2.5。

## 提醒说明

独立闹钟仅保存在此设备，不进入课表备份或云同步。当前为单次日期闹钟，不包含重复闹钟。
响铃最长 10 分钟；强行停止应用后需重新打开。关机、未授予权限、厂商省电限制仍可能影响提醒。
Android 15 模拟器已验证锁屏、后台进程被回收后的唤醒及 5 分钟稍后提醒；各品牌真机仍需验收。

## 管理后台

入口 `https://8.154.43.154/admin/`。管理员与普通用户账号隔离，密码仅存 Argon2 哈希；会话采用 Secure/HttpOnly Cookie、CSRF 校验及限流，重置操作留有审计记录。
管理端沿用测试 CA，电脑需先信任提供的 CA 才能正常访问；不要使用 HTTP 输入密码。服务器证书到期时间仍为北京时间 2026-11-01 22:33:56，正式运营前需续签或切换公开可信证书。
管理员通过容器内 `python -m backend.create_admin <username>` 创建，密码从标准输入读取，不在源码或镜像内预设。
