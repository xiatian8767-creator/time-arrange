# 3.2beta.1 弹窗与账号功能

后台地址：`https://8.154.43.154:8443/admin/`。登录后选择 **App 弹窗 → 新建弹窗**。

新版升级 H5：`https://8.154.43.154:8443/updates/3.2beta.1/`。页面包含更新说明、安装前备份提示和 HTTPS 安装包下载入口。此页面已准备好，但不会自动向用户投放；由运营人员自行配置和启用弹窗。

推荐填写：名称“Star Orbit 新版更新”，宽度 88、高度 78，开始时间选择需要发布的北京时间。先用“自定义用户”选择自己的用户 ID 检查效果，再按需要改为“全部用户”。每次进入 App 最多展示一个符合条件的弹窗，新开始的活动优先。

频次按活动和账号计算：1 次为该活动总计一次；每天以北京时间零点划分；每周以北京时间周一划分。编辑原活动保留展示记录，如确需新的独立活动，请新建。用户可以直接关闭弹窗。未到开始时间、已停用、用户不在投放范围或次数已用完时不显示。网络和 H5 加载失败不阻塞正常使用，失败页面不记为已展示。

页面支持 HTTP 和 HTTPS，支持默认端口及 8080、8443。HTTPS 仍需有效证书，HTTPS 页面不加载混合明文子资源。独立原生 WebView 不注入账号和本机数据接口，禁止文件与内容访问。安装包链接交给手机浏览器下载，应用不会自动安装更新。

## 接口及兼容

- 新增数据库表：`account_recovery`、`app_campaigns`、`campaign_receipts`，启动时增量创建，不重建已有用户和课表表。
- `GET/POST /api/v1/me/security`：读取设置状态／核验当前密码后保存两道保密问题及答案哈希。
- `POST /api/v1/auth/recovery/questions`、`POST /api/v1/auth/recovery/reset`：读取保密问题／核验答案并重置密码，重置后撤销原会话。
- `GET /api/v1/campaigns`：返回当前账号下一条可展示活动；`POST /api/v1/campaigns/{id}/displayed`：网页加载成功后记录展示。
- `GET/POST /admin/api/campaigns`、`POST /admin/api/campaigns/{id}`：管理员查询、新建与修改，写操作要求 CSRF 令牌和编辑版本号。

新注册账号有待设置保密问题状态，客户端在设置完成前保持登录引导。原有账号无此新增记录，可继续使用并自行在设置中补充。旧版 API 客户端保持兼容。保密答案不进入同步文档或任何接口返回，使用 Argon2 加盐哈希；设置需验证当前密码，重置有用户名限速及持久化失败锁定。

源码中的运营说明和技术文档仅供维护；用户界面保持简洁。
