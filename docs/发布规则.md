# 发布规则

- 官网只展示稳定版、探索版两个下载入口。
- 按队列递进：新探索版上线时，上一轮官网探索版转为稳定版。未上线官网的中间版本不会自动进入队列。
- 稳定版保留原安装包，不重新构建或覆盖。当前版本位置统一查看 README 与官网源码，不在多份文档重复记录。
- 用户未确认官网发布前，只提供独立下载/H5 和 GitHub Release，不擅自替换首页。
- 对外统一称“探索版”，不称“测试版”。H5 只介绍用户可见变化并附下载入口；投放任务由用户自行配置。
- 更新 Manifest 的 versionCode / versionName、构建输出名及当前官网配置，沿用原签名。
- 发布前检查两个下载入口、包哈希、版本、反馈入口与必要健康接口。声明自动测试和真机验收边界。
- Git 提交使用中文；历史说明和安装包交给 Git / GitHub Releases 管理，不新建逐版总结、验证记录或源码压缩包。
