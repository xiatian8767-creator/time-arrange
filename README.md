## 1.2 搭子课表

- 课表页点击“搭子课表”，选择“配置导入”，可导入搭子的 JSON 课表配置或旧版完整备份。
- 推荐双方使用同一弹窗中的“导出我的课表配置”分享文件；该文件仅包含本人课程和作息，不含待办。
- 确认导入后显示只读搭子课表，可一键切回自己的课表。搭子课程可点击查看地点及备注，不能修改。
- 搭子作息独立显示；导入、替换及移除都不改变自己的课程、待办或通知。
- 搭子课表独立保存在手机上，重启保留，启动默认显示本人课表。“设置与备份”的个人备份不包含搭子副本，请保留原配置文件。
- “联网申请”仅为入口提示，本版不联网、不需要账号。配置是静态副本，搭子更新后需要重新导入。
- 安装包：`dist/StarTimetable-1.2.5.apk`，versionCode 8，沿用原签名。更新前建议导出个人备份。

离线安卓课表与事务待办。首次打开是空白课表，采用暖白背景和分区时间表，金色五角星标出当前星期与时间。无账号、无联网权限。

## 安装和使用

安装 `dist/StarTimetable-1.2.5.apk`。本次沿用原签名，可覆盖旧版安装。建议先在设置中导出备份；卸载会删除本机数据。

- 底部切换“课表”和“事务待办”。课表页可以添加课程、修改作息、切换周次；点卡片编辑或删除。
- “今天”返回当前周与时间位置；五角星每 15 秒刷新。查看其他周时隐藏。
- 待办支持标题、日期时间、优先级、备注、完成/恢复、编辑删除，以及待完成/今天/全部/已完成筛选。
- 新增需要提醒的待办时允许系统通知。在待办页按提示开启“准时提醒”（系统的闹钟和提醒权限）；未允许准时提醒时使用系统非精确调度，可能延迟。
- 通知由安卓调度，不依赖页面一直打开。完成、删除、关闭提醒或修改时间会重新安排通知；重启、系统时间调整、应用更新和返回应用时会重新核对。
- 系统强行停止应用后，需要重新打开才能恢复提醒。厂商省电限制可能影响送达；关机期间错过的提醒恢复后最多补发过去 24 小时内的项目。
- 设置中导出/导入全部课表与待办。导入会替换现有数据；“恢复空白课表”会清空课程并恢复初始作息，保留待办。

最低 Android 6.0（API 23），需要现代系统 WebView（建议 80+）；已实测 Android 15 模拟器，未覆盖各品牌真机。

## 源码和构建

`app/src/main/assets/` 是离线界面与业务代码；`app/src/main/java/cn/xingke/timetable/` 是安卓容器、持久化和通知。详细流程见 `开发者说明文档.md`。

准备 JDK 17+、Android SDK Platform 35、Build Tools 35.0.0，然后执行：

```powershell
.\build.ps1 -JavaHome 'C:\path\to\jdk-17' -AndroidSdk 'C:\path\to\Android\Sdk'
```

输出在 `test/build/StarTimetable-1.2.5.apk`。脚本完成资源编译、Java 编译、DEX、对齐、签名及验证，无需 Gradle 或 npm。也可用 `-BuildTools` 和 `-Platform` 指定工具与 android.jar 的完整位置。`-DebugBuild` 仅供本地验证。

`signing/` 只保留在本机，不放入源码压缩包或 GitHub。从源码包首次构建会生成新密钥，因此独立构建的包不能覆盖本次签名安装包。请妥善保留原项目的签名文件。

`test/` 存放临时 SDK、模拟器、构建和截图；`tests/` 是本地回归脚本。两者及 `dist/`、`signing/` 均不提交 Git。交付源码包只含应用代码、构建脚本和文档。

数据格式版本 2，包含 `slots`、`courses`、`todos`，兼容版本 1 备份。备份最大 1 MB。课程仍按每周重复，不支持单双周、学期调课或云同步。
